# Независимые испытания

## Запуск

```bash
uv run python -m quantum_link_optimizer.experiments.validation.run \
  --development artifacts/experiments/forecast-benefit-01 \
  --plan lab/experiments/independent-trials.json \
  --output artifacts/experiments/independent-trials-01
uv run python -m quantum_link_optimizer.experiments.validation.stress \
  --plan lab/experiments/queue-pressure.json \
  --output artifacts/experiments/queue-pressure-01
```

Каждый запуск требует новый каталог
Модель и план фиксируются в `policy-lock.json` до первого final
96 эпизодов имеют одинаковый snapshot кода до и во время серии
Seeds 1009/1013 не пересекаются с development, переобучения на final нет

## Условия

Восемь сценариев × два seed × шесть политик × 22 команды = 2112 поступлений
Норма, смена быстрого пути, оба пути 700 мс, медленный KMS, пустой пул,
общая очередь, рестарт получателя и потери A

Нагрузка 13,3 команды/с, в development — 10/с
Генератор не ждёт ACK, задержка считается от запланированного поступления
Очередь, pacing, отказы и unknown входят в знаменатель

Убедительного преимущества ML нет
12 рестартов сохранили состояние SQLite, повторных исполнений в серии нет

## Производительность

Восемь open-loop прогонов: bypass, fixed B, EWMA, прогноз × sync/deferred
В каждом 1000 команд при подаче 1000/с, все получили ACK ≤100 мс

| Политика | Решение p99 sync / deferred, мкс |
| --- | ---: |
| Fixed B | 65,4 / 72,4 |
| EWMA | 85,2 / 74,7 |
| Прогноз | 195,1 / 205,4 |

- Цель решения 100 мкс выполнена для правил, превышена для прогноза
- Измерение решения не включает последующую сериализацию события
- Команда около 310 UDP-байт, протокол не поддерживает 1024 прикладных байта
- Spans обработки p99 0,42–0,52 мс охватывают часть пути, бюджет 1 мс не подтверждён
- CPU/RSS измерены для общего процесса sender/receiver/KMS/relay
- Deferred сохраняет сериализацию и откладывает диск в буфер до 64 МиБ

## Переполнение очереди

Отдельный план: 200 команд при 1000/с, RTT 20 мс, queue limit 4
В sync и deferred по 12 исполнений и 188 отказов `queue_full`
Все поступления учтены, опыт не использовался для настройки модели

## Границы результата

Диагностика считает KMS-сигналы TP/FP/FN и unknown по условиям стенда
Это не точная классификация атак или физических причин
Серия выполнена на одном macOS arm64-хосте, данные сети оператора не использованы
