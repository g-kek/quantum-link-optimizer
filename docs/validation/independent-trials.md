# Независимые испытания и overhead — issue #7

7 ноября 2026. Лабораторная приёмка на одном macOS arm64-хосте, Python 3.12.
Модель и preprocessing из [#6](../research/forecast-benefit.md) не переобучались.
Это ограниченный эксперимент, не длительная серия 64 часа и не операторский пилот.

## Протокол и воспроизведение

```bash
uv run python -m quantum_link_optimizer.experiments.validation.run \
  --development artifacts/experiments/forecast-benefit-01 \
  --plan lab/experiments/independent-trials.json \
  --output artifacts/experiments/independent-trials-01
uv run python -m quantum_link_optimizer.experiments.validation.stress \
  --plan lab/experiments/queue-pressure.json \
  --output artifacts/experiments/queue-pressure-01
```

Каталоги новые. До первого final фиксируется `policy-lock.json`: хеши модели,
manifest/report development, полный план, политики и критерии. Изменение модели
или development запрещено. Seeds 1009/1013 были зарезервированы в плане #6;
пересечения с train 11/23 и validation 101 нет. Все 96 final-эпизодов имеют
одинаковый source snapshot, созданный до опытов. Версия кода серии: `3dc989a`.

Восемь условий × два seeds × шесть политик × 22 команды = 2112 поступлений.
Входной темп 13,3/с вместо development 10/с. Добавлены не встречавшиеся в обучении
общая очередь, потери A и настоящий рестарт UDP-получателей с переоткрытием
SQLite на тех же адресах. Норма, смена быстрой ветви, оба пути 700 мс, медленный
KMS и исчерпание ключей остаются обязательными контролями.

Генератор не ждёт ACK. Своевременность считается от запланированного поступления;
опоздание event loop включено. Все поступления, очередь, отказы, pacing и unknown
входят в знаменатель. RTT успешных ACK и задержки всех завершений показаны
раздельно. Времена KMS/RTT/receiver при копиях могут перекрываться: их распределения
нельзя складывать как непересекающиеся части одной операции.

| Fixed A | 102 / 352 | 104 | 0 |
| Fixed B | 23 / 352 | 114 | 0 |

| Прогноз | 128 / 352 | 105 | 0 |
| EWMA + копии | 137 / 352 | 100 | 65390 |
| EWMA + pacing | 9 / 352 | 80 | 0 |

Разница прогноз−EWMA: +1 команда, +0,284 п.п. Описательный bootstrap по 16 целым
парным эпизодам: интервал [0; +0,852] п.п. Ноль входит в интервал; оснований
объявлять преимущество или включать прогноз по умолчанию нет. Это не доверительный
интервал для сети РЖД: повторяются лишь восемь лабораторных семейств условий.

Двенадцать рестартов сохранили исполненное состояние; повторных исполнений
во всех 96 эпизодах нет. Это проверка лабораторной идемпотентной операции set,
а не универсальная exactly-once гарантия для внешнего оборудования.

## Производительность и границы бюджетов

Отдельно выполнены восемь open-loop прогонов: bypass без Router, fixed B,
EWMA и прогноз, каждый с sync/deferred-журналом; по 1000 команд, подача 1000/с,
нулевая заданная сетевая задержка и та же AEAD-защита/SQLite/KMS. Во всех восьми
прогонах 1000/1000 подтверждены за 100 мс с учётом опоздания генератора.

| Политика | Решение p99 sync / deferred, мкс |
| --- | --- |
| Fixed B | 65,4 / 72,4 |
| EWMA | 85,2 / 74,7 |
| Прогноз | 195,1 / 205,4 |

Для измеренного участка решения простые политики уложились в 100 мкс,
прогноз — нет. Решение включает snapshot, inference, выбор и диагностику;
последующая сериализация события измерением не охвачена.

**Исходный полный бюджет не подтверждён.** Фактический UDP payload команды
около 310 байт. Протокол поддерживает скалярный set и wire limit 1200 байт;
1024 прикладных байта не помещаются в текущую JSON/base64/AEAD-упаковку.
Нельзя переименовать 1024 UDP-байта в 1024 прикладных и объявить цель выполненной.

Измеренные crypto/store spans дают лишь нижнюю границу обработки: p99 примерно
0,42–0,52 мс. Некоторые parsing/dispatch/cache-участки не охвачены, поэтому
это не доказательство полного бюджета агента 1 мс, тем более на неподдерживаемой
прикладной нагрузке. CPU/RSS относятся ко всему совместно размещённому процессу
sender/receiver/KMS/relay и экспорту. Для строгой приёмки нужны отдельные процессы,
контракт полезной нагрузки и инструментирование полного критического пути.

Deferred откладывает диск, сохраняя сериализацию и запись в ограниченный буфер
64 МиБ. Это не «журналирование выключено». Влияние I/O показано отдельно.

Дополнительная диагностика очереди объявлена отдельным планом до её запуска:
200 поступлений при 1000/с, RTT 20 мс, queue limit 4. В sync и deferred по
12 исполнений и 188 явных отказов `queue_full`; все 200 исходов сохранены.
Она выполнена после основной серии, не использовалась для обучения или выбора политики.

## Диагностика и ограничения

Отчёт сохраняет observed/candidate/insufficient статусы, unknown и число
KMS-сигналов TP/FP/FN по объявленному активному условию (для исчерпания — только
после фактического опустошения). Это проверка сетевых/ключевых признаков на
момент решения, не точная классификация причин и не обнаружение атак.
Ошибка либо отсутствие диагноза не скрываются как успешное определение причины.

[Полная численная сводка, ошибки диагностики и хеши](../evidence/independent-trials.json).
Сырые события, модель, lock, source snapshots и manifest — в указанных каталогах
`artifacts/experiments/`. Данные целевой сети не получены; выводы на неё не переносятся.
